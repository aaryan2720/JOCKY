# JOCKY API Contract & Specification

## Base URL
- Local Development: `http://localhost:8000`
- API Version: `v1` (`/api/v1`)
- WebSocket Root: `ws://localhost:8000/ws`

---

## 1. System Health

### `GET /health`
Returns health and availability status of the management server.

**Response `200 OK`**:
```json
{
  "status": "ok",
  "service": "jocky-backend",
  "version": "0.1.0",
  "timestamp": "2026-09-29T12:00:00Z"
}
```

---

## 2. Agent Management (`/api/v1/agents`)

### `GET /api/v1/agents`
List registered fleet agents with status and metadata filters.

**Query Parameters**:
- `status`: `online` | `offline` | `busy` (optional)
- `os`: `windows` | `linux` | `darwin` (optional)
- `limit`: `integer` (default: 50)
- `offset`: `integer` (default: 0)

**Response `200 OK`**:
```json
{
  "total": 2,
  "items": [
    {
      "id": "agent-df84b2c1",
      "hostname": "FIN-SRV-01",
      "os": "windows",
      "version": "0.1.0",
      "status": "online",
      "ip_address": "10.0.10.45",
      "last_seen": "2026-09-29T12:00:00Z",
      "cert_fingerprint": "sha256:4a8b...9f"
    }
  ]
}
```

### `POST /api/v1/agents/register`
Agent registration & enrollment endpoint.

**Request Body**:
```json
{
  "token": "jocky-enrollment-token",
  "hostname": "FIN-SRV-01",
  "os": "windows",
  "arch": "amd64",
  "agent_version": "0.1.0"
}
```

**Response `201 Created`**:
```json
{
  "agent_id": "agent-df84b2c1",
  "status": "enrolled",
  "heartbeat_interval_seconds": 5
}
```

## 3. Forensic Scripts (`/api/v1/scripts`)

### `POST /api/v1/scripts/validate`
Validates a JOCKY DSL script without persisting or executing.

**Request Body**:
```json
{
  "body": "COLLECT processes WHERE name == 'powershell.exe'; CHECK yara(rule: 'cobalt_strike');"
}
```

**Response `200 OK`**:
```json
{
  "valid": true,
  "ast_summary": { "statements": 2 },
  "estimated_artifacts": ["process_list"]
}
```

### `GET /api/v1/scripts`
List saved forensic inspection scripts.

### `POST /api/v1/scripts`
Create a new JOCKY script.

---

## 4. Job Orchestration & Deployment (`/api/v1/jobs`)

### `POST /api/v1/jobs`
Dispatches a compiled JOCKY execution plan to selected target agents.

**Request Body**:
```json
{
  "script_id": "script-001",
  "target_agent_ids": ["agent-df84b2c1"],
  "target_tags": ["production", "finance"]
}
```

**Response `202 Accepted`**:
```json
{
  "job_id": "job-78a9c2",
  "status": "queued",
  "agent_count": 1,
  "created_at": "2026-09-29T12:00:00Z"
}
```

### `GET /api/v1/jobs/{job_id}`
Get job execution state and summary metrics.

---

## 5. Artifacts & Evidence (`/api/v1/artifacts`)

### `POST /api/v1/artifacts`
Ingests forensic artifacts collected by endpoint agents and triggers automated adversary detection.

**Request Body** (single or array):
```json
[
  {
    "job_id": "job-78a9c2",
    "agent_id": "agent-df84b2c1",
    "type": "process",
    "data": {
      "pid": 4812,
      "name": "mimikatz.exe",
      "path": "C:\\Temp\\mimikatz.exe",
      "signature_status": "unsigned"
    }
  }
]
```

**Response `201 Created`**:
```json
[
  {
    "id": "art-19f8a3c42b10",
    "job_id": "job-78a9c2",
    "agent_id": "agent-df84b2c1",
    "type": "process",
    "data": {
      "pid": 4812,
      "name": "mimikatz.exe",
      "path": "C:\\Temp\\mimikatz.exe",
      "signature_status": "unsigned"
    },
    "collected_at": "2026-09-30T09:40:00Z"
  }
]
```

### `GET /api/v1/artifacts`
Query forensic artifacts collected from agents.

**Query Parameters**:
- `job_id`: filter by originating job (optional)
- `agent_id`: filter by agent identifier (optional)
- `type`: filter by artifact type (`process`, `network`, `persistence`, `eventlog`) (optional)
- `limit`: integer (default: 100)
- `offset`: integer (default: 0)

### `GET /api/v1/artifacts/{artifact_id}`
Retrieve a specific artifact by its identifier.

## 6. Threat Detections & Correlation (`/api/v1/detections`)

### Implemented Rule Identifiers
- `PROC-UNSIGNED-001`: Unsigned process executable identified on endpoint.
- `PROC-NET-001`: Unsigned process with active network connection correlated across PID and host within time window.
- `PROC-PARENT-001`: Suspicious process lineage / parent-child anomaly based on configured rule pairings.
- `FLAG-DYNAMIC-001`: Dynamic condition match from JOCKY DSL `flag` statement in compiled execution plan.

### `GET /api/v1/detections`
Retrieve threat detections generated by the adversary detection and correlation engine.

**Query Parameters**:
- `agent_id`: filter by agent identifier (optional)
- `job_id`: filter by job ID (optional)
- `severity`: filter by severity (`low`, `medium`, `high`, `critical`) (optional)
- `status`: filter by status (`open`, `acknowledged`, `resolved`, `false_positive`) (optional)
- `rule_id`: filter by rule ID (e.g. `PROC-UNSIGNED-001`) (optional)
- `limit`: integer (default: 100)
- `offset`: integer (default: 0)

**Response `200 OK`**:
```json
{
  "total": 1,
  "items": [
    {
      "id": "det-a7c83f9e1201",
      "agent_id": "agent-df84b2c1",
      "job_id": "job-78a9c2",
      "rule_id": "PROC-NET-001",
      "severity": "high",

      "description": "Process PID 4812 (mimikatz.exe) reported unsigned and was associated with TCP connection 10.0.0.5:4444.",
      "status": "open",
      "created_at": "2026-09-30T09:40:02Z",
      "evidence": [
        {
          "artifact_id": "art-19f8a3c42b10",
          "type": "process",
          "details": {
            "pid": 4812,
            "name": "mimikatz.exe",
            "path": "C:\\Temp\\mimikatz.exe",

    }
  ]
}
```

## 7. Real-Time WebSocket Updates (`/ws`)

### `WS /ws/jobs/{job_id}`
Real-time stream of incoming artifacts, agent execution status, and live alerts for an active forensic triage job.

**Stream Event Example**:
```json
{
  "event": "artifact_collected",
  "job_id": "job-78a9c2",
  "agent_id": "agent-df84b2c1",
  "timestamp": "2026-09-29T12:00:02Z",
  "payload": {
    "type": "process",
    "item": { "pid": 4812, "name": "powershell.exe" }
  }
}
```
